# План работ — MVP Content Factory

> Текущая согласованная стратегия. Источник: `zametna_content_factory_mvp_plan.pdf`.

Как довести первый Editorial Window до ~14 реально публикуемых
Instagram-постов за 1–2 рабочих дня с помощью AI + human-in-the-loop.

- **Режим:** human-in-the-loop
- **Первая глава:** September Soft Power
- **Объём:** ≈14 posts / 1–2 days

**North Star:** сегодня начали → завтра/послезавтра у нас есть готовые 14
постов, которые не стыдно публиковать. MVP измеряется результатом и
скоростью, а не процентом автоматизации.

---

## 01 · Definition of Done

Не «полностью автономный контент-завод», не идеальный AI-router, не 100%
автоматизированная fashion production. Первый MVP готов, когда система быстро
производит достаточный объём контента нужного качества.

- **14** публикуемых постов (не просто 14 генераций)
- **1–2** рабочих дня на весь production cycle
- **AI + HIL** — рабочий режим, ручной отбор допустим

**Главный критерий:** человек открывает сетку и говорит: «Да, это выглядит как
один сильный fashion account, а не случайный AI-каталог».

**Минимальные quality gates:**

- Пост достаточно сильный для публикации.
- Одежда узнаваемо соответствует реальным товарам.
- Модель достаточно консистентна между публикациями.
- Нет явного «AI catalogue feel».
- Есть разнообразие поз, планов, движения и сцен.
- Визуально чувствуется одна production-команда.
- EW направляет контент, но не душит разнообразие.
- Финальный human review пройден.

## 02 · Editorial Window v1 — меньше правил, больше направления

Editorial Window должен быть **weighted editorial context**: усиливать
вероятность согласованного мира, но не превращать каждый пост в экзамен на
соответствие десятку правил.

**P0 · Hard Brand Boundaries:** premium; adult feminine; contemporary;
desirable, confident; controlled sensuality; без teenage / cheap party /
vulgar / theatrical luxury.

**Soft EW Vibe:** возвращение к городскому ритму после лета; polished urban
femininity; confidence without hardness; early-autumn feeling; city / work /
dinner / gallery / home / weekend — как возможные моменты.

**Логика отбора:** противоречит Brand World → REJECT | сильный EW match →
BOOST | нейтрально, но «наша женщина» → ALLOW.

**Рабочее правило:** спрашиваем не «выражает ли этот пост EW на 100%?», а
«противоречит ли он миру EW?». Если нет — он может жить внутри главы.

**Не делать сейчас:** жёсткие квоты по work/date/home; фиксировать буквально
один город; превращать EW в rigid storyboard на 14 постов.

## 03 · Creative Engine — главный bottleneck: fashion energy

Система уже умеет делать «приличную fashion-картинку», но слишком легко
сходится к безопасному шаблону: full-body, фронтально, рука у воротника,
взгляд в сторону, красивое здание.

1. **Creative Reference Pool (P0).** Собрать 30–100 одобренных fashion
   references — не по одежде, а по пластике, motion, framing, camera angle,
   взаимодействию со средой и харизме. VLM извлекает: pose · action · body
   language · camera · composition · energy · interaction with environment.
2. **Shot Concept до генерации (P0).** Генерировать не «фон», а момент.
   Формула: OUTFIT + MOMENT + ACTION + BODY LANGUAGE + CAMERA + ENVIRONMENT.
3. **Варианты вместо single-shot (P0).** На каждый hero outfit — 3–4 разных
   shot concepts → 3–4 candidates → выбирать лучший по creative score.
4. **Creative Evaluator (P0).** Отдельно от fidelity проверять: fashion
   energy, pose originality, motion, composition, scene story, charisma,
   catalogue feel. Ниже порога — regenerate с конкретным feedback.
5. **Vector Similarity / Anti-Template Memory (P2, следующий этап).** Хранить
   embeddings shot concepts / carousel concepts и позже самих generated frames,
   чтобы измерять не только «качество», но и **насколько идея шаблонна и похожа
   на уже сделанное**. Сравнивать: кадры внутри одной карусели; новую карусель с
   недавними каруселями/shot concepts; идеи с Creative Reference Pool. Это даёт
   soft novelty / repetition signal, помогает находить near-duplicates даже при
   разной формулировке и использовать vectors как retrieval/контроль в разных
   точках pipeline. Vector similarity — не oracle качества и не hard reject:
   высокий similarity может быть осознанной серией, низкий не означает хороший
   fashion. Решение остаётся за creative score + human review.

## 04 · Carousel System — карусель как мини-история

Для каждого hero outfit заранее планируем роли кадров:

1. **Hero** — главный fashion frame, full или 3/4, самый сильный крючок.
2. **Motion** — walking, turning, entering, leaving, wind, движение ткани.
3. **Mid / Portrait** — поясной или 3/4: лицо, характер, жесты, детали верха.
4. **Detail** — ткань, пояс, вырез, рукав, обувь, сумка, фурнитура.
5. **Mood** — environmental / candid-feeling / unusual composition.

**Правило:** не обязательно всегда 5 кадров, иногда 3 достаточно. Но нельзя
делать full-body × 5.

**Anti-repeat checks:** не повторять hand-to-collar gesture в одном batch;
менять угол тела, направление взгляда, положение рук; смешивать static и
motion; не повторять один и тот же camera distance.

**Первый production test:** не генерить все 14 постов сразу. Сначала 1 сильный
hero outfit → полноценная пилотная карусель → review → масштабирование.

## 05 · Visual World — связанный мир без одинаковых фонов

Нужна не одна локация, а несколько **location families** внутри одного уровня
вкуса. Environment reference задаёт визуальную семью, а не помещение для копии
1:1.

| Family | Роль | Примеры |
|---|---|---|
| City Architecture | Core city / work | stone, glass, entrances, stairs, restrained facades |
| Polished Public Interior | Meetings / transition | hotel, private club, lobby, corridor |
| Gallery / Design Space | Fashion-forward chapter | clean lines, art, architectural interiors |
| Evening | Dinner / date | restaurant, bar, warm dark interior |
| Home | Private / weekend | sophisticated apartment with a real moment |

**Environment system:** референс задаёт taste level и mood; генерируется новое
пространство той же семьи; сцена содержит действие/момент; не требуем
буквальную Москву или одну географию.

**Visual Preset v1:** premium natural light; единый envelope по color
temperature; спокойный контраст и natural skin; consistent shadow character;
единое ощущение lens / grain / highlight rolloff.

**Цель:** разные сцены и времена суток, но ощущение, что их сняла одна сильная
fashion-команда.

## 06 · Identity + Product Fidelity — два строгих evaluator'а перед human review

**Identity Consistency (P1, before final 14).** Identity Anchor Pack из 3–5
сильных референсов (front, 3/4, profile, medium/full). Anchor = единственный
source of truth для лица. Product models никогда не влияют на identity. Hero
можно как continuity reference, но не вместо anchor pack. Отдельный identity
evaluator → fail → regenerate.

**Product Fidelity 1:1 (P1, before final 14).** Оригинальные product
references — hard truth; Visual Passport помогает, но не заменяет фото.
Проверять silhouette, proportions, color, fabric, drape, seams; neckline,
sleeves, waistband, pockets, hem, hardware. Отдельный fidelity evaluator по
каждому товару → fail → конкретный feedback → regenerate из original refs.

**Поток:** original product refs + identity pack → generation → identity eval +
fidelity eval → human review.

**Критическое правило:** не «ремонтировать» плохую генерацию через неё же. Для
retry всегда возвращаться к исходным product references и identity anchors,
иначе drift накапливается.

## 07 · Selection & Learning — не зацикливаться на одних товарах и позах

**Outfit / Anchor Diversity (P0/P1).** Кеш экономит LLM calls, но не даёт
старому good_anchor структурное преимущество. Учитывать: product recency;
silhouette recency; category / brand coverage; outfit formula repetition;
novelty score как мягкий бонус, а не жёсткая квота.

**Human Feedback Logging (P1).** Каждый reject сохраняет причину: pose_boring ·
too_catalogue · identity_drift · product_mismatch · wrong_scene ·
duplicate_pose · bad_light · not_premium.

**Что пока НЕ строить:** Dynamic Router с десятками ограничений и
автопоследовательностью постов. Для первых 14 достаточно ручной 3×5 / 4×4 grid
review. После 30–50 публикаций автоматизировать только то, что человек реально
повторяет. **Принцип MVP: manual selection first, complex routing later.**

## 08 · Target Architecture — Content Factory v1

```
LIVE CATALOGUE → AI STYLIST → STRONG OUTFIT → EW SOFT CONTEXT
    ↓
SHOT / CAROUSEL PLANNER + CREATIVE REFERENCES + ENVIRONMENT FAMILY + VISUAL PRESET
    ↓ soft check later: VECTOR SIMILARITY / ANTI-TEMPLATE MEMORY
IMAGE GENERATION
    ↓
CREATIVE EVAL + IDENTITY EVAL + PRODUCT FIDELITY EVAL
    ↓ fail → feedback → regenerate · pass ↓
HUMAN APPROVAL → CONTENT POOL → MANUAL GRID → PUBLISH
```

**Разделение evaluator'ов:**

- **Creative** — хорошая ли это fashion-фотография?
- **Identity** — это всё ещё наша узнаваемая женщина?
- **Fidelity** — одежда действительно соответствует реальным товарам?

## 09 · Execution Roadmap — порядок работ

| Приоритет | Действие | Результат |
|---|---|---|
| P0 | 1. Смягчить EW prompt | Меньше overfit к формальным правилам |
| P0 | 2. Visual Preset v1 | Одна production language |
| P0 | 3. Environment Families v1 | Связанный мир без одинаковых фонов |
| P0 | 4. Shot / Carousel Planner | Hero + motion + mid + detail + mood |
| P0 | 5. Creative Reference Pool | Fashion energy, позы, пластика, camera ideas |
| P0 | 6. Creative Evaluator + retry | Автоматически выбраковывать скучные кадры |
| P0 | 7. Fix anchor/repetition selection | Не зацикливаться на одних товарах/формулах |
| P1 | 8. Identity Anchor Pack + eval | Стабильное лицо перед финальным production |
| P1 | 9. Product Fidelity eval + retry | Максимальное приближение к 1:1 |
| P1 | 10. Human feedback logging | Данные для следующей автоматизации |
| P2 | 11. Vector similarity / anti-template layer | Контроль near-duplicates, шаблонности и novelty на уровне concepts / carousels / references |

**После P0:** взять один уже выбранный сильный outfit и сделать полноценную
пилотную карусель. Если workflow работает — масштабировать, а не продолжать
стратегические обсуждения.

## 10 · Production Run — как собрать первые ~14 постов

1. **Pilot.** 1 сильный hero outfit → 3–5 shot concepts → генерации →
   creative / identity / fidelity review → финальная карусель.
2. **Scale.** Если pilot проходит review — ещё 2–3 карусели, проверить, не
   повторяется ли визуальный шаблон.
3. **Fill gaps.** Добрать work/meeting, softer private/daytime,
   more fitted/structured и non-blouse silhouette.
4. **Build the 14.** Собрать ≈14 hero posts. Не обязательно 14×5 изображений:
   среднее 3 хороших кадра на пост уже даёт полноценную первую волну.

**Final 14-post review:** нет 3–4 одинаковых поз подряд; нет одного и того же
outfit formula по всей сетке; есть full / mid / detail / motion variation;
несколько сценариев жизни одной женщины; visual preset и quality level не
прыгают; лицо и product fidelity приемлемы; нет ощущения случайного
AI-каталога; всё реально можно поставить в очередь публикации.

**Final DoD:** 14 publishable posts · 1–2 working days · AI + human-in-the-loop.
Если это достигается — первый MVP Content Factory сделан. Всё остальное
оптимизируем по данным реального production.
