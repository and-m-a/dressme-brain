# Стратегия контент завод

!!Данный файл ИИ агентам трогать запрещается

Цели

1. Финальная цель - Автоматизированная ИИ команда / система для полного цикла контент маркетинга
2. MVP - Контент завод с помощью которого можно сгенерировать +- 14 постов каруселей за 1-2 дня, с минимальным ручным контролем

План MVP1
1. Есть сущность конетнт, контент бывает разных рубрик, разных форматов
2. Для генерации контента используется флоу, заранее определенный набор шагов
3. Перед генерацией контента добавляем creative бриф который учитывают все шаги
4. Добавляем базу референсов чтобы примерно понимать чего мы хотим

План этап 2

1. Генерация рилсов
2. ИИ сбор референсов и анализ конкурентов
3. ИИ анализ самого флоу, авто предложения по доработкам
4. ИИ анализ статистики публикаций и предложения для корректировки контент стратегии
